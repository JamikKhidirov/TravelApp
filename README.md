## 🔍 О проекте

**TravelApp** – это нативное Android-приложение, которое помогает путешественникам находить выгодные туристические предложения, а администраторам – управлять ими через отдельную панель.

Проект реализован с **модульным подходом**: каждый функциональный блок (геолокация, камера, Bluetooth, синхронизация и т.д.) вынесен в отдельный модуль `core`. Это упрощает тестирование, поддержку и переиспользование кода.

**Две сборки:**
- 🧳 **TravelApp** – для пользователей (поиск, фильтрация, детали, бронирование)
- 🛠 **TravelAdmin** – для администраторов (CRUD туров, управление категориями, статистика)

## ✨ Ключевые возможности

### 👤 Пользовательская часть
- 📋 **Каталог туров** – карточки с фото, ценой, рейтингом
- 🔍 **Умная фильтрация** – по стране, дате, цене, звёздам
- 📍 **Геолокация** – подбор туров рядом с пользователем
- 📸 **Отзывы с фото** – загрузка через камеру или галерею
- 🔔 **Push-уведомления** – новые предложения и акции
- 📶 **Офлайн-режим** – кэширование данных (Room)
- 🌙 **Тёмная тема** (в плане)

### 🛠 Административная панель
- ➕ **Добавление/редактирование/удаление** туров
- 🏷 **Управление категориями** и тегами
- 📊 **Статистика** по просмотрам и бронированиям
- 👥 **Управление пользователями** (блокировка, роли)

### ⚙️ Технические фичи
- 📱 Поддержка Android 7.0+ (API 24)
- 🌐 Синхронизация с REST API
- 📦 Чёткое разделение на модули
- 🧪 Покрытие юнит-тестами (JUnit, MockK)
- 🤖 CI/CD через GitHub Actions и Fastlane
- 🔄 Автоматическая сборка и публикация в Google Play (при необходимости)

## 🧱 Архитектура и структура

```bash
TravelApp/
├── applications/                     # Точки входа (сборки)
│   ├── TravelApp/                    # Пользовательское приложение
│   └── TravelAdmin/                  # Админ-панель
├── core/                             # Модули ядра (переиспользуемые)
│   ├── battery/                      # Статус заряда батареи
│   ├── bluetooth/                    # Bluetooth-соединения
│   ├── camera/                       # Камера и галерея
│   ├── common/                       # Общие утилиты, расширения, DI
│   ├── contacts/                     # Доступ к контактам
│   ├── device/                       # Информация об устройстве
│   ├── location/                     # Геолокация (GPS)
│   ├── network-info/                 # Мониторинг сети
│   ├── sensors/                      # Датчики (акселерометр, гироскоп)
│   ├── storage/                      # SharedPreferences, Room, кэш
│   └── sync/                         # Синхронизация с сервером
├── fastlane/                         # Автоматизация (Fastlane)
├── gradle/                           # Gradle-скрипты, версионирование
└── .github/workflows/                # CI/CD (GitHub Actions)
```
## 📋 Требования

- Android Studio Hedgehog (2023.1.1) или новее

- JDK 17 (или 11)

- Android SDK (API 24+)

- Gradle 8.2 (обёртка уже есть)

## ⚙️ Конфигурация
Для работы приложения необходимо задать переменные окружения и ключи API.
Создай файл local.properties в корне проекта или используй secrets.gradle:

```
# local.properties
API_BASE_URL="https://your-api-server.com"
API_KEY="your_api_key_here"
MAPS_API_KEY="your_google_maps_key"
Все чувствительные данные должны быть исключены из VCS (добавлены в .gitignore).
```

## 🤖 CI/CD
**Проект использует GitHub Actions для автоматической сборки, тестирования и деплоя.
Конфигурация находится в .github/workflows/ci.yml.**

**Основные этапы:**

- ✅ Линтинг (ktlint)

- ✅ Сборка всех модулей

- ✅ Запуск юнит-тестов

- ✅ Сборка APK/AAB (при необходимости)

**Дополнительно Fastlane настроен для публикации в Google Play (скрипты в fastlane/).**
