# Скриншоты приложения

Здесь лежат реальные скриншоты/записи экранов TravelApp, которые вставляются в корневой `README.md`.

## Как добавить

1. Сделай скриншоты с запущенного эмулятора или устройства:
   - Android Studio → **View → Tool Windows → Logcat → Screenshot**, либо
   - `adb exec-out screencap -p > home.png`
2. Положи файлы в эту папку под такими именами:

   | Файл | Экран | Что показать |
   |------|-------|--------------|
   | `home.png` | Главный экран | поиск, табы «Ближащие / Популярные», города, карточки туров |
   | `search.png` | Поиск | строка поиска и список популярных мест |
   | `home-loading.png` | Состояние загрузки | shimmer-скелетоны до прихода данных |
   | `no-internet.png` | Ошибка сети | экран «Что-то пошло не так» и кнопка «Повторить попытку» |

3. Запись экрана в GIF (для блока «Анимации»):

   ```bash
   adb shell screenrecord /sdcard/demo.mp4
   adb pull /sdcard/demo.mp4 .
   # конвертация в GIF (любым инструментом, например ffmpeg)
   ffmpeg -i demo.mp4 -vf "fps=12,scale=360:-1" demo.gif
   ```

4. Вставь их в `README.md` в раздел **«Скриншоты и анимации»**:

   ```html
   <img src="docs/screenshots/home.png" width="240" alt="Главный экран">
   ```

## Важно

- Не коммить скриншоты с API-ключами, e-mail и персональными данными.
- Пока реальных скриншотов нет, в README используется анимированный макет `docs/assets/screens-demo.svg` — он рисуется прямо на GitHub и не требует файлов-изображений.
